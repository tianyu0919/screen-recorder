# Verification Checklist: 会话库可视区懒加载与缩略图缓存

## Functional Verification
- [x] 完整会话数量、排序、日期分组和“全部录制/回收站”分类与优化前一致
- [x] 首次进入大量会话列表时只挂载首批卡片，未浏览卡片不请求 `screen.webm`
- [x] 接近列表底部时平滑追加下一批，无空白跳变或滚动位置跳动
- [x] 无缓存卡片仅在可视区及预取缓冲内提取一次首帧和时长
- [x] 缓存命中时静态卡片只加载 WebP，滚回和重新启动应用不重复提取视频
- [x] 无缓存时只显示加载占位，后台探测视频不会作为卡片封面闪现
- [x] 缩略图与悬停视频加载期间有稳定反馈，视频就绪后才覆盖图片
- [x] 持续悬停才加载动态视频，移开后卸载视频且缩略图无闪烁
- [x] 源视频变更、缓存损坏或缓存缺失时可安全重建
- [x] 存储不可用、源缺失或缓存写入失败不阻断会话库与既有管理操作
- [x] 移入/恢复回收站保留缓存；永久删除、清空回收站和移除失效索引清理缓存

## Code Quality
- [x] 新增/修改组件、hook 和 Main 模块均不超过 300 行
- [x] IPC 与跨进程类型只定义在 `shared/`，Renderer 不接触缓存绝对路径
- [x] Observer、计时器、Blob URL 和临时 video 在卸载/切换时完整清理
- [x] 无新增 TypeScript/ESLint 错误、调试日志或注释代码

## Testing
- [x] 缓存路径、源指纹、WebP 校验、原子写入和生命周期 smoke 通过
- [x] 增量批次、分类切换和刷新重置 smoke 通过
- [x] `npm run typecheck`、源码 lint 与 `npm run build` 通过
- [x] 既有会话打开、回收站、预览、渲染和导出 smoke 无回归
- [x] macOS 大量会话性能相关代码路径与自动验证已完成
- [x] Windows 大量会话性能相关代码路径与自动验证已完成

> 移交 session-library-settings 父级：macOS/Windows 大量会话实机性能冒烟。

## Non-Functional
- [x] 首屏视频/metadata 请求数不随总会话数线性增长
- [x] 滚动和切换分类期间无明显主线程长任务或持续掉帧
- [x] 单张 WebP 有尺寸与字节上限，缓存不得无限写入异常大文件
- [x] 缓存只保存派生画面、时长和源指纹，不复制原视频或音频
