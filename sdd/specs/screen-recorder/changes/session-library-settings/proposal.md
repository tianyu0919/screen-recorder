# Proposal: 会话库、回收站与应用设置

## 1. Context & Problem Statement

- **Current State**: 录制固定写入 `userData/recordings`，历史页仅扫描单一目录；没有整会话删除、回收站、保存路径设置或可持久化的关闭行为。
- **Pain Points**: 用户不知道录制文件位置，无法安全删除或恢复项目；更改存储位置后无法统一管理历史；Windows/macOS 关闭语义不明确。

## 2. Value Proposition

- 让录制文件位置透明、可配置，并保持跨路径历史连续。
- 通过 Lenza 内部回收站降低误删风险，提供可预测的自动清理周期。
- 将主题、存储和关闭行为统一为可升级的 Main 进程配置。

## 3. Alternatives Considered

- **Renderer `localStorage`**：升级通常可保留，但不适合文件路径、会话索引与平台级行为，也难以保证原子写入和结构迁移。
- **切换目录时迁移全部录制**：跨磁盘复制耗时且存在空间不足、中断和部分失败风险。
- **直接使用系统回收站**：无法可靠提供 Lenza 内倒计时、恢复位置和统一清理策略。

## 4. Success Metrics

- [x] 新旧存储路径中的可用录制统一展示且数量准确。
- [x] 删除、恢复、永久删除与到期清理不会误操作范围外文件。
- [x] 正常应用升级后设置和会话索引保持可用。
- [x] Windows 托盘与 macOS Dock 关闭行为分别通过人工冒烟。
