# Verification Checklist: 会话库、回收站与应用设置

## Functional Verification
- [x] 首次启动默认路径为系统视频目录下的 `Lenza`，设置页可显示、选择和打开路径。
- [x] 修改路径后不搬迁旧录制，新旧根目录的录制数量合并正确。
- [x] 存储根离线显示“存储位置不可用”，恢复连接后可重新打开。
- [x] 根可访问但会话目录缺失时显示“源文件已被移除”，且只能移除失效索引。
- [x] 普通删除经过确认后进入内部回收站，恢复后返回原列表和原位置。
- [x] 永久删除单项与清空回收站均有不可恢复二次确认。
- [x] 保留周期支持 1、3、7、30 天和永久，默认 3 天。
- [x] 三档倒计时格式准确，不足 1 小时按分钟和秒更新。
- [x] 到期项目在启动与运行期间清理；失败时保留并可重试。
- [x] 设置面板可修改主题、路径、保留周期和关闭行为。
- [x] 未保存关闭策略时每次提示；勾选“不再提示”或设置后不再提示。
- [x] Windows 后台运行隐藏至托盘且可恢复；macOS 隐藏并保留 Dock 且可恢复。
- [x] Windows 盘符/反斜杠与 macOS POSIX 路径均通过目录边界、移动、恢复和删除验证。
- [x] Windows 预览文件占用时不会产生半删除状态，释放资源后可重试成功。
- [x] macOS 关闭、隐藏、Dock 激活和无窗口状态下始终只恢复一个主窗口。
- [x] 正常升级/配置 schema 扩展后既有设置和索引保持可用。

## Safety & Error Handling
- [x] 所有磁盘操作在 Main 完成，Renderer 仅使用白名单 IPC。
- [x] 目录规范化和根路径约束可阻止路径穿越及范围外删除。
- [x] 移动、恢复、清理或配置写入失败时，不提前提交错误状态。
- [x] 正在录制或导出的会话不会被删除。
- [x] 所有错误使用中文友好提示，不显示原始堆栈。

## Code Quality
- [x] 新增/修改的页面与模块文件均不超过 300 行。
- [x] 平台实现按 `darwin.ts`、`win32.ts` 与薄分发层拆分。
- [x] `npm run lint` 无错误或警告。
- [x] `npm run typecheck` 通过。
- [x] `npm run build` 通过。
- [x] `docs/TECH_DESIGN.md` 与 `sdd/project.md` 已同步。

## Manual Testing
- [x] 1280×800 与 1440×900 下历史页、回收站、设置和确认弹窗无明显布局问题。
- [x] 鼠标、键盘、focus、ARIA 与 reduced-motion 行为通过冒烟。
- [x] Windows 与 macOS 分别完成人工平台验证；任一平台未验证时不得将本规格标记为 completed。
- [x] 原有录制、预览、编辑、播放和导出流程无回归。
