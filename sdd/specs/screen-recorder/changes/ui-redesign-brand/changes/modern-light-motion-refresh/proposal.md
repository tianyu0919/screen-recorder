# Proposal: Lenza 现代浅色界面与动效升级

## 1. 背景与问题

- **当前状态**：项目已完成 Lenza 品牌、录制页、会话历史、预览编辑器、深浅主题与基础组件库，录制、IPC、预览、编辑和导出链路均已有真实实现。
- **问题**：现有视觉体系以深色为主，部分组件仍使用硬编码色值、渐变背景和零散交互样式；视图切换、卡片进场、录制反馈、导出完成反馈等缺少统一且尊重减弱动态偏好的动效；录制、历史、编辑三类工作区的视觉层级和桌面工具质感仍需统一。
- **约束**：本变更只升级表现层、交互反馈和动效，不改变采集语义、`events.json`、IPC 契约、录制状态机、编辑数据、播放器渲染管线或导出实现。

## 2. 价值主张

- 以浅灰、橙红强调色、柔和圆角、细边框和轻阴影形成克制、专业的桌面工具视觉。
- 保留浅色、深色和跟随系统主题，浅色作为默认及主要验收主题，两套主题共用语义化 token。
- 让录制、播放、调参、导出和浏览历史的状态反馈更明确，同时保持现有业务链路稳定。
- 通过组件拆分和统一 Motion 约定，降低后续页面迭代的视觉与无障碍维护成本。

## 3. 备选方案

- **仅覆盖 CSS，不调整组件边界**：改动较少，但难以统一页面过渡、stagger、交互状态和响应式折叠，且会继续积累大组件中的表现逻辑。
- **重写三套页面并用静态演示数据代替现有 store**：容易快速贴近截图，但会破坏真实录制、会话、编辑和导出链路，不可接受。
- **在现有组件与 store 上做视觉层重构（采用）**：复用真实数据与行为，仅在必要处拆分展示组件、引入 Motion 包装和语义化 token。

## 4. 成功指标

- [ ] 1280×800 与 1440×900 下，录制准备、录制历史、预览编辑三个视图无明显溢出或遮挡。
- [ ] 浅色与深色主题均可切换且信息层级、对比度、焦点态完整，浅色首次启动为默认主题。
- [ ] 录制、播放、滑杆、开关、会话卡片、视图切换和导出反馈均连接现有真实业务状态。
- [ ] 所有新增动效在 `prefers-reduced-motion: reduce` 下关闭或显著降级。
- [ ] TypeScript、lint（若项目脚本缺失则先补齐可执行的 lint 配置）和生产构建通过。
- [ ] Windows Electron 实机完成三视图与关键交互冒烟；macOS 特有窗口行为列入人工回归项。
