# Verification Checklist: Lenza 现代浅色界面与动效升级

## 规格与边界

- [ ] 所有 `spec.md` 场景均有对应实现和可观察证据。
- [ ] 录制、IPC、窗口控制、会话落盘、播放器、时间轴和导出业务语义未被表现层重构替换或绕过。
- [ ] 未使用 localStorage 存放业务数据；仅允许延续主题偏好用途。
- [ ] 受影响的组件/模块文件均不超过 300 行，且复用了已有相近实现。

## 主题与视觉

- [ ] 首次启动默认浅色，system/light/dark 三种主题模式均可切换并持久化偏好。
- [ ] 浅色背景为浅灰、中性表面层级清晰，橙红只用于重要操作、选中和品牌强调。
- [ ] 深色主题下三视图、错误态、焦点态和深色预览画布均清晰可辨。
- [ ] 受影响 UI 未使用紫色渐变、装饰性渐变光球、emoji 或无意义统计数字。
- [ ] 受影响 UI 不含 `text-white`、`bg-white`、`bg-black` 等直接颜色工具类；颜色由语义 token 派生。
- [ ] 字体不超过两种，品牌名为 Lenza，其余可见界面文字为中文。
- [ ] `src/index.html` metadata、根主题色和 Lenza 品牌保持一致，CSP 未被削弱。

## 录制准备页

- [ ] 顶部展示 Logo、Lenza、指定描述、主题/窗口控件、录制/预览切换和三项真实权限状态。
- [ ] 屏幕与窗口分区展示真实源；卡片含缩略图、名称、checkbox/选中状态，刷新与空状态可用。
- [ ] 底部录制栏固定且包含麦克风、系统音频、录制/停止、计时、错误和上次录制入口。
- [ ] 录制按钮有克制呼吸、hover/tap 和录制中状态，并在 reduced-motion 下关闭循环动画。

## 历史与预览编辑

- [ ] 历史页展示会话数量、刷新、今天/昨天等日期分组、真实缩略图、时长和录制 ID。
- [ ] 历史卡片 hover/focus 上移 4px 并显示操作反馈；鼠标与键盘均可进入真实会话。
- [ ] 编辑页顶部展示返回、日期、ID、时长、分辨率、FPS、适应/100%、文件位置和导出。
- [ ] 深色预览画布正确绘制真实视频；设置面板可折叠且含全部指定运动、音频、裁剪和会话信息。
- [ ] 所有指定滑杆可用鼠标与键盘调整，数值实时更新且预览/导出仍消费同一现有数据。
- [ ] 时间轴始终位于编辑页底部，播放/暂停、时间、刻度、运动、键盘事件、音频、seek、缩放、平移和裁剪可用。
- [ ] 导出展示真实 loading/progress、成功、失败及取消反馈，实际产物路径/格式行为无回归。

## Motion、响应式与无障碍

- [ ] 页面切换使用 AnimatePresence；列表/网格使用 staggerChildren；按钮有轻微 tap scale；卡片 hover 等效 `y: -4`。
- [ ] 页面进入分组淡入且卡片依次出现，不存在持续占用主线程或影响视频帧回调的动画。
- [ ] `prefers-reduced-motion: reduce` 下循环、stagger 和明显位移动画关闭或显著降级。
- [ ] 1280×800 与 1440×900 下三视图无明显溢出、遮挡或不可达操作。
- [ ] 较小窗口中设置面板可折叠，时间轴仍固定底部，布局主要使用 flex/grid。
- [ ] 所有关键按钮、滑杆、checkbox、开关和会话卡片具有中文可访问名称、键盘操作和清晰 focus-visible。
- [ ] 视图切换和动画未引发额外采集源/会话数据请求或业务状态丢失。
