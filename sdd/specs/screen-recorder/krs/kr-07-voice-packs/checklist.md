# Verification Checklist: 本地语音包与非破坏式变声

## Functional Verification
- [ ] 含麦克风会话展示原声、低沉、清亮、广播和机器人，且至少 4 个非原声预设可生成
- [ ] 无麦克风会话明确禁用语音包，不影响系统音频、自定义音轨和无麦克风导出
- [ ] 生成过程显示进度、取消和可重试错误，取消/失败不改变当前有效音轨
- [ ] 选择原声立即恢复 `mic.wav`，任何操作均未覆盖或修改原文件
- [ ] 相同源指纹、preset 和 engine 版本命中缓存，不重复处理
- [ ] 页面/会话切换期间任务和结果严格按 `sessionId` 隔离
- [ ] 派生文件缺失或损坏时回退原声并提示，不静默产生预览/导出不一致
- [ ] 麦克风增益和静音对当前派生轨生效，原声不会被重复混入
- [ ] 视频裁剪后派生轨与画面同步，被裁内容不进入预览和导出
- [ ] 历史 edit 文档迁移后默认原声，其他编辑状态不丢失
- [ ] 清理派生音频不会删除原始麦克风或当前仍在使用的资产

## Audio Quality & Timing
- [ ] 所有派生 WAV 与原始麦克风采样率、声道数和样本数一致
- [ ] 低沉/清亮不通过 playbackRate 改变总时长
- [ ] 30 分钟会话片尾声画误差不超过 20ms
- [ ] 分块边界无明显爆音、断裂或音量突变
- [ ] 输出无数字削波；长静音区不会产生持续明显噪声
- [ ] macOS 与 Windows 对相同输入和版本产生一致的时长与主要效果

## Code Quality
- [ ] 逐样本 DSP 仅运行在 Worker，React/Main 热路径无逐样本循环
- [ ] 新增/修改文件不超过 300 行，重复 DSP/缓存逻辑已提取
- [ ] IPC 和跨进程类型仅定义在 `shared/`，派生文件路径经过严格校验
- [ ] 无新增 TypeScript/ESLint 错误、调试日志或注释代码

## Testing
- [ ] DSP 等长、峰值、静音、分块、缓存、取消和迁移 smoke 全部通过
- [ ] `npm run typecheck`、lint 和 `npm run build` 通过
- [ ] 既有麦克风/系统音频、自定义音轨、预览同步、裁剪和导出无回归
- [ ] macOS 人工端到端冒烟通过
- [ ] Windows 人工端到端冒烟通过

## Non-Functional
- [ ] 生成期间编辑播放和页面交互无明显卡顿
- [ ] 取消、失败和重复生成后 Worker、监听器及临时文件均被释放
- [ ] 所有预设完全本地工作且不需要下载 AI 模型或上传音频
- [ ] 预设参数和引擎均版本化，升级后不会错误复用旧缓存
