# Proposal: 本地语音包与非破坏式变声

## 1. Context & Problem Statement

- **Current State**: Lenza 已支持麦克风/系统音频增益、静音、自定义音轨和统一导出混音，但麦克风只能使用原始音色。
- **Pain Points**:
  - 用户制作教程、演示或趣味内容时，需要离开 Lenza 使用外部软件变声并重新导入音轨。
  - 直接覆盖 `mic.wav` 会破坏原始素材，无法比较或恢复。
  - AI 音色转换涉及大模型、硬件差异、人物声音授权和较高打包成本，不适合作为第一期默认能力。

## 2. Value Proposition

- 提供原声、低沉、清亮、广播、机器人等本地语音包，在编辑页一键生成并试听。
- 所有效果通过平台无关 DSP 在 Worker 中离线处理，macOS/Windows 行为一致且不依赖网络。
- 原始麦克风轨永不修改，用户可随时切回原声或更换语音包。
- 派生音轨接入现有预览同步和导出混音，保持裁剪、音量、静音与视频时间轴一致。

## 3. Alternatives Considered

- **实时录制变声**：反馈即时，但会把 DSP 负载带入录制热路径并增加设备延迟，不作为第一期。
- **RVC/其他 AI Voice Conversion**：能逼真替换人物音色，但模型大、跨平台推理复杂，并存在声音授权与滥用风险，留作独立后续 KR。
- **字幕转 TTS 配音**：能修改文案并生成标准旁白，但会改变原始语气且需要逐段时长适配，留作字幕完成后的独立 KR。
- **选定方案：本地离线 DSP 语音包**：以固定、可审计的参数预设处理完整 `mic.wav`，输出等长派生 WAV。

## 4. Success Metrics

- [ ] 含麦克风的会话可选择至少 4 个非原声音包并生成可试听派生轨。
- [ ] 原始 `mic.wav` 始终不变，原声与任意已缓存语音包可无损切换。
- [ ] 派生轨与原轨采样数一致，30 分钟会话片尾声画误差不超过 20ms。
- [ ] 页面切换、取消、失败和重复生成不会造成结果串会话或残留临时文件。
- [ ] macOS 与 Windows 的预览及导出结果听感和时长一致。
