# Proposal: 本地实时字幕与字幕编辑

## 1. Context & Problem Statement

- **Current State**: Lenza 已把麦克风录制为 `mic.wav`，编辑器支持运镜、裁剪和多类音轨，但没有语音转写、字幕轨、字幕样式或字幕导出。
- **Pain Points**:
  - 产品演示和教程仍需依赖外部工具生成字幕并二次合成。
  - 录制者无法在录制中确认麦克风是否被正确识别。
  - 外部字幕难以与 Lenza 的源时间轴裁剪、预览和导出保持一致。
  - 仅在预览层叠加 HTML 字幕无法进入现有 OffscreenCanvas/WebCodecs 导出路径。

## 2. Value Proposition

- 录制、识别、字幕精修和导出在同一项目内完成，减少工具切换。
- 本地转写避免上传原始麦克风内容，符合桌面录屏工具的隐私预期。
- 录制中临时字幕提供即时反馈；停录后双遍校正保证最终字幕可编辑、可复现。
- 字幕进入统一时间轴与合成管线，可正确处理裁剪并同时产出烧录 MP4 与 SRT。

## 3. Alternatives Considered

- **云端实时转写 API**：开发速度快、模型维护成本低；但依赖网络、持续计费且上传音频，不作为默认方案。
- **Windows/macOS 系统语音 API**：包体较小；但双平台能力、语言和时间戳语义不同，会造成结果漂移和平台分支膨胀。
- **仅停录后转写**：实现风险较低；但不能满足录制中的字幕反馈。
- **仅实时结果直接落盘**：延迟低；但滑动窗口会反复改写文字，最终准确率和时间戳不稳定。
- **选定方案：本地 whisper.cpp 双遍识别**：录制中生成临时结果，停录后基于完整 `mic.wav` 重新生成最终结果；模型首次使用按需下载。

## 4. Success Metrics

- [ ] 字幕功能关闭或失败时，录屏、预览和导出既有链路无回归。
- [ ] 推荐硬件上临时字幕在说话后 2.5 秒内出现，且不造成明显录屏掉帧。
- [ ] 停录后生成可编辑的最终字幕，所有段落时间均位于真实视频片尾内。
- [ ] 字幕位置与样式在预览和烧录 MP4 中一致，裁剪后 SRT 时间轴正确映射。
- [ ] Windows 与 macOS 均能完成模型下载、实时临时字幕、最终转写和字幕导出。
