# Verification Checklist: 本地实时字幕与字幕编辑

> **历史验收范围**：第一期验收以
> [post-recording-captions/checklist.md](./changes/post-recording-captions/checklist.md) 为准；实时字幕条目不作为本期完成条件。

## Functional Verification
- [ ] 模型首次启用可查看进度、取消和重试；校验失败不加载损坏文件
- [ ] 自动检测、中文、英文三种语言选项可用并记住上次选择
- [ ] 录制中临时字幕只来自麦克风，并显示在不被捕获的悬浮窗
- [ ] 实时转写落后或崩溃时录屏不中断，停止后仍能用完整 WAV 生成最终字幕
- [ ] 停录后字幕状态从生成中进入完成或可重试失败态
- [ ] 历史会话和无麦克风会话正常加载，不要求存在 `captions.json`
- [ ] 字幕轨支持修改、拖边、分割、合并、删除，且不改变原始音视频
- [ ] 全局样式包含已确认的字体、字号、颜色、描边、背景、透明度、圆角、对齐、最大宽度和淡入淡出
- [ ] 画布拖动可修改全局位置；单条字幕位置覆盖不影响其他字幕
- [ ] 字幕始终位于输出安全区，长文本按最大宽度换行
- [ ] MP4 烧录字幕与预览视觉一致；关闭烧录后视频不含字幕
- [ ] SRT 时间合法递增，视频裁剪后时间映射正确，跨裁剪区字幕按保留段分割

## Code Quality
- [ ] 新增/修改的组件、hook 和 Main 模块均不超过 300 行
- [ ] 跨进程类型和通道仅定义在 `shared/`
- [ ] 平台差异拆分为 darwin/win32/index，平台无关逻辑不重复
- [ ] 无新增 TypeScript 错误、调试日志或注释代码

## Testing
- [ ] 字幕纯逻辑与 helper 协议专项 smoke 全部通过
- [ ] `npm run typecheck` 通过
- [ ] `npm run build` 通过
- [ ] 既有 render/export/audio smoke 无回归
- [ ] Windows 人工端到端冒烟通过
- [ ] macOS 人工端到端冒烟通过

## Non-Functional
- [ ] 推荐硬件临时字幕在说话后 2.5 秒内出现
- [ ] AudioWorklet、IPC 和 helper 有界队列，慢识别不造成录屏掉帧或内存持续增长
- [ ] 模型和音频默认只在本地处理，无隐式网络上传
- [ ] 预览与导出使用同一字幕布局/渲染实现
- [ ] 模型、helper 或字体失败均显示用户可读错误并安全降级
- [ ] 安装包包含对应平台 helper 与内置字体，模型目录位于 userData 且可清理
