# Verification Checklist: 录制后离线字幕生成与编辑

## Functional Verification
- [ ] 新会话和历史会话在存在 `mic.wav` 时均可按需生成字幕
- [ ] 无麦克风会话显示明确说明且预览、编辑、导出不受影响
- [ ] 模型首次下载显示体积、进度、取消和重试；校验失败不加载损坏文件
- [ ] 自动检测、中文和英文选项均可用
- [ ] 页面/会话切换后任务继续且状态按 `sessionId` 隔离，不出现结果串会话
- [ ] 同一会话不能并发启动多个任务，显式取消会终止 helper 并清理临时结果
- [ ] 转写成功后原子生成合法 `captions.json`；失败不覆盖已有字幕
- [ ] 重新生成已有字幕前显示覆盖确认，取消确认不修改文档
- [ ] 字幕轨支持修改、拖边、分割、合并和删除，且不改变原始音视频
- [ ] 全局样式、全局位置和单段位置覆盖在普通预览、专注预览与导出一致
- [ ] 字幕位于输出安全区，长文本按最大宽度换行
- [ ] MP4 可独立开关字幕烧录；SRT 使用裁剪后时间轴并正确分割跨裁剪字幕

## Code Quality
- [ ] 新增/修改的组件、hook、Main 模块均不超过 300 行
- [ ] IPC 通道和跨进程类型只定义在 `shared/`
- [ ] 平台实现按 `darwin.ts`、`win32.ts`、`index.ts` 拆分
- [ ] 推理不运行在 Renderer 主线程，页面卸载不产生遗留监听或跨会话写入
- [ ] 无新增 TypeScript/ESLint 错误、调试日志或注释代码

## Testing
- [ ] 字幕纯逻辑、SRT、模型校验、helper 协议和任务隔离 smoke 通过
- [ ] `npm run typecheck`、lint 和 `npm run build` 通过
- [ ] 既有录制、预览、裁剪、渲染、导出和音频 smoke 无回归
- [ ] macOS 人工端到端冒烟通过
- [ ] Windows 人工端到端冒烟通过

## Non-Functional
- [ ] 字幕关闭、取消或失败不阻断既有录屏与导出流程
- [ ] 模型和录音默认只在本机处理，无隐式上传
- [ ] 转写任务进度可观察、可取消，内存不会随失败重试持续增长
- [ ] 预览与导出复用同一字幕布局和位图渲染实现
- [ ] helper、模型、字幕文件或字体失败均显示用户可读错误
