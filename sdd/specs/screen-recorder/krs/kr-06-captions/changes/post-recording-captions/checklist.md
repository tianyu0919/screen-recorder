# Verification Checklist: 录制后离线字幕生成与编辑

## Functional Verification
- [ ] 新录像字幕默认关闭；历史录像恢复上次开关状态
- [ ] 关闭字幕后预览、导出、轨道和所有操作平滑隐藏，已有字幕数据不丢失
- [ ] 首次开启直接使用内置 Whisper/VAD 生成；中途关闭可取消并清理临时结果
- [ ] VAD + 词级时间戳生成的一句话字幕贴合实际说话起止区间
- [ ] 连续编辑显示待保存、保存中、已保存；失败状态可重试
- [ ] 时间轴右键添加默认 2 秒字幕，遇下一段自动缩短并进入编辑
- [ ] SRT 仅在开启时可导入，按原始录像时间轴确认后替换现有字幕
- [ ] 新会话和历史会话在存在 `mic.wav` 时均可按需生成字幕
- [ ] 无麦克风会话显示明确说明且预览、编辑、导出不受影响
- [ ] 内置模型缺失或校验失败时提示安装资源损坏，不加载损坏文件
- [ ] 自动检测、中文和英文选项均可用
- [ ] 新生成字幕默认选择中文与高精度模型；中文或自动检测为中文的结果统一保存为简体中文
- [ ] 页面/会话切换后任务继续且状态按 `sessionId` 隔离，不出现结果串会话
- [ ] 同一会话不能并发启动多个任务，显式取消会终止 helper 并清理临时结果
- [ ] 转写成功后原子生成合法 `captions.json`；失败不覆盖已有字幕
- [ ] 重新生成已有字幕前显示覆盖确认，取消确认不修改文档
- [ ] 字幕轨支持修改、拖边、分割、合并和删除，且不改变原始音视频
- [ ] 全局样式、全局位置和单段位置覆盖在普通预览、专注预览与导出一致
- [ ] 字幕位于输出安全区，长文本按最大宽度换行
- [ ] MP4 可独立开关字幕烧录；SRT 使用裁剪后时间轴并正确分割跨裁剪字幕
- [ ] Windows/macOS 安装包均内置可用的 Whisper Small + VAD，离线首次生成不发起模型下载
- [ ] Base 档位与模型按需下载流程已完全移除（未上线，无存量缓存兼容负担）
- [ ] 合法自定义模型经格式、摘要和 helper 探测后原子导入，并在重启应用后长期显示
- [ ] 非法、不兼容或复制中断的模型不进入注册表，且临时文件被清理
- [ ] 已生成字幕记录稳定模型 ID/名称，再次进入录像时恢复对应模型和字幕数据
- [ ] 历史字幕文档无模型字段时仍可读取并默认回显内置 Small
- [ ] 自定义模型删除前确认，删除不影响任何已有字幕；内置 Small/VAD 不可删除
- [ ] 已用模型删除或丢失后显示“模型已缺失”，已有字幕仍可编辑、预览、导出，重新生成被安全阻止

## Code Quality
- [x] 新增/修改的组件、hook、Main 模块均不超过 300 行
- [x] IPC 通道和跨进程类型只定义在 `shared/`
- [x] 平台实现按 `darwin.ts`、`win32.ts`、`index.ts` 拆分
- [x] 推理不运行在 Renderer 主线程，页面卸载不产生遗留监听或跨会话写入
- [x] 无新增 TypeScript/ESLint 错误、调试日志或注释代码

## Testing
- [x] 字幕纯逻辑、SRT、模型注册表、helper 协议和任务隔离 smoke 通过
- [x] `npm run typecheck`、lint 和 `npm run build` 通过
- [x] 既有录制、预览、裁剪、渲染、导出和音频 smoke 无回归
- [ ] macOS 人工端到端冒烟通过
- [ ] Windows 人工端到端冒烟通过
- [ ] Windows 内置/导入/重入/删除/缺失模型冒烟通过
- [ ] macOS 内置/导入/重入/删除/缺失模型冒烟通过

## Non-Functional
- [x] 字幕关闭、取消或失败不阻断既有录屏与导出流程
- [x] 模型和录音默认只在本机处理，无隐式上传
- [x] 转写任务进度可观察、可取消，内存不会随失败重试持续增长
- [x] 预览与导出复用同一字幕布局和位图渲染实现
- [x] helper、模型、字幕文件或字体失败均显示用户可读错误
