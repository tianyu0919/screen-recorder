# Verification Checklist: 鼠标跟随稳定性与提前响应

## Functional Verification

- [ ] 稳定画面内不超过视口短边 3% 的鼠标微动不会改变相机目标。
- [ ] 持续大幅移动会触发一次连续跟随，鼠标完成移动前相机已开始响应。
- [ ] 跟随完成后，鼠标在新位置附近轻微移动不会让相机继续黏着移动。
- [ ] 鼠标再次跨越触发阈值时可自然启动下一次跟随。
- [ ] 移动中反向不会产生密集往返关键帧、瞬移或明显过冲。
- [ ] 鼠标接近画布四边时相机正确钳制，无黑边。
- [ ] 稀疏、空轨迹、旧会话、裁剪和 seek 均安全降级且不报错。

## Code Quality

- [ ] 算法保持纯函数和确定性，不读取实时系统光标或 DOM。
- [ ] 不修改 `events.json`、共享 IPC 或编辑文档格式。
- [ ] 相关源文件不超过 300 行，无新增调试日志和无关依赖。
- [ ] `npm run typecheck` 与 `npm run build` 通过。
- [ ] cursor-follow、render 和 export smoke 通过。

## Manual Testing

- [ ] macOS 与 Windows 真实会话均确认跟随柔和、响应及时、稳定区无抖动。
- [ ] 预览与导出抽查相同时间点，相机位置一致。
