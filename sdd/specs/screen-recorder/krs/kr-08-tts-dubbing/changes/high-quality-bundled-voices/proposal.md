# Proposal: 高质量内置中英文 TTS 音色

## 1. Context & Problem Statement

- **Current State**: kr-08 当前内置 Melo 中英单音色与 Theresa 多说话人模型，并提供 Fanchen 按需下载。真实中文测试表明 Theresa 原始 22.05kHz 分段 WAV 已包含明显高频毛刺和局部电音；正式派生轨还使用线性重采样与缺少边界淡化的分段拼接，进一步放大不自然感。
- **Pain Points**:
  - 部分内置音色在未经过变速和拼接前已经存在明显电音，无法靠后处理彻底修复。
  - Melo 仅提供一个中英音色，英文词汇还受有限 lexicon 约束，不能覆盖用户对独立中文、英文音色的需求。
  - 旧模型同时存在“内置、按需下载、自定义导入”三种资源路径，官方音色的产品口径不统一。
  - 线性升采样、硬切段边界和现有 WSOLA 缺少固定质量基准，模型替换后仍可能产生卡顿、爆音或机械感。

## 2. Value Proposition

- 同时提供中英混读、中文专用、英文专用三类本地音色，让用户按内容选择自然度更高的模型。
- 官方音色全部随安装包内置，首次使用不等待下载，macOS 与 Windows 行为一致。
- 删除已验证质量不达标的官方模型与下载路径，减少 UI 噪声和模型管理分支。
- 用带限重采样、边界淡化和可回归的变速质量测试守住最终派生 WAV 的听感。

## 3. Alternatives Considered

- **只保留 Melo**：包体最小，但音色单一，英文词汇覆盖受限，不能解决现有质量与选择问题。
- **仅用 Kokoro 中英模型**：集成简单，但用户已明确要求同时提供中文、英文专用模型。
- **CosyVoice 3 / IndexTTS 作为默认引擎**：自然度高，但 Python/PyTorch 运行时、模型体积和硬件要求不适合当前轻量跨平台 helper。
- **继续保留 Theresa/Fanchen 作为“实验音色”**：会继续暴露已知电音风险，与“内置即可靠”的产品预期冲突。

## 4. Success Metrics

- [x] 内置 Kokoro 中英、Matcha 中文、Kokoro 英文三套模型，离线安装后无需下载即可生成。
- [x] Melo、Theresa、Fanchen 不再出现在清单、UI、构建资源或官方下载代码中。
- [ ] 固定中英测试语料的原始段与最终派生轨均无可闻电音、爆音、重复音节或断续。
- [ ] 48kHz 派生轨段首、段尾和截断点无单样本硬跳变，变速段保持音高且无明显金属感。
- [ ] macOS 与 Windows 对三套模型完成生成、预览和导出冒烟。
