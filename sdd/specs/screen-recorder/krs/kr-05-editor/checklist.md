# Verification Checklist: kr-05-editor

> 每条客观可验证，全部勾选后方可关闭本 KR。

## Functional Verification
- [ ] 自动关键帧在时间线上可视化展示，可拖拽移动且预览即时刷新
- [ ] 可手动新增关键帧（指定 x/y/zoom）与删除自动关键帧，spring 插值正确重算
- [ ] 关键帧越界（时长外 / zoom 非法值）被钳制并提示，不产生坏数据
- [ ] 删除中间片段后导出视频时长正确减少，删除点前后画面与事件衔接正确，关键帧时间戳同步平移
- [ ] 删除区间覆盖关键帧时，删除点相机状态由相邻关键帧插值接管，无跳变
- [ ] 含 webcam 的会话可开启画中画，位置/尺寸可调，预览与导出一致且时间轴同步
- [ ] 按键事件时刻叠加按键徽章，组合键/高频输入正确合并显示、不遮挡画面主体
- [ ] 编辑数据会话级持久化：重开会话后编辑结果仍在

## Edge Case Verification
- [ ] 无 webcam 素材的会话画中画开关置灰并提示，不影响其他功能
- [ ] 无 keys 事件的会话（降级录制）按键回显层正常为空，不报错
- [ ] 全部编辑操作的结果在预览与导出（kr-03 管线）中一致（抽查对比）

## Code Quality & Non-Functional
- [ ] 无新增 TypeScript 类型错误与 lint 告警；生产路径无调试残留
- [ ] 编辑交互流畅（拖拽关键帧/选区无明显卡顿）
- [ ] macOS 与 Windows 双平台冒烟通过（含 webcam 采集）
