# Verification Checklist: kr-05-editor

> 每条客观可验证，全部勾选后方可关闭本 KR。

## Functional Verification
- [x] 自动运镜效果在时间线上可视化展示，可拖拽移动且预览即时刷新
- [x] 可手动新增/删除运镜效果，spring 插值正确重算
- [x] 运镜越界（时长外 / zoom 非法值）被钳制并提示，不产生坏数据
- [x] 删除中间片段后导出视频时长正确减少，删除点前后画面与事件衔接正确，关键帧时间戳同步换算
- [x] 删除区间覆盖运镜时，删除点相机状态连续且无明显跳变
- [ ] 含 webcam 的会话可开启画中画，位置/尺寸可调，预览与导出一致且时间轴同步
- [x] 按键事件时刻叠加按键徽章，组合键/高频输入正确合并显示、不遮挡画面主体
- [x] 编辑数据会话级持久化：重开会话后编辑结果仍在

## Edge Case Verification
- [ ] 无 webcam 素材的会话画中画开关置灰并提示，不影响其他功能
- [x] 无 keys 事件的会话（降级录制）按键回显层正常为空，不报错
- [x] 已交付编辑操作的结果在预览与导出（kr-03 管线）中一致（抽查对比）

## Code Quality & Non-Functional

- [x] 编辑交互流畅（拖拽运镜/选区无明显卡顿）
- [ ] macOS 与 Windows 双平台冒烟通过（含 webcam 采集）
