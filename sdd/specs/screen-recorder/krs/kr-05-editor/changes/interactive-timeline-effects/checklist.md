# Verification Checklist: 可编辑运镜、事件与自动保存

## Functional Verification
- [x] 运镜主体移动保持时长，左/右手柄分别修改对应边界
- [x] 运镜最短 300ms、100ms 精度、磁性吸附、源边界和禁止重叠均生效
- [x] 手动运镜使用当前全局倍率/时长且不生成波纹
- [x] 自动运镜整体移动与左边缘调整同步关联波纹，右边缘不移动波纹
- [x] 删除自动运镜同步隐藏关联波纹/点击点，删除手动运镜不影响点击
- [x] 编辑后的焦点与波纹使用新时间的鼠标位置，空轨迹安全降级到画布中心
- [x] 短运镜块 Hover 显示倍率、开始、结束和持续时长
- [x] 左键时间轴只 seek；右键不 seek，并按空白/素材上下文显示正确菜单
- [x] 右键可在目标时间添加运镜、键盘提示和音频
- [x] 检查器不再显示“添加音轨”，已有音轨音量和删除仍可使用

## Keyboard & Overlay
- [x] 新录制不保存无修饰普通字符，快捷键/功能键/单独修饰键正确保存
- [x] `Ctrl + C` 等组合规范化，长按重复不会产生提示风暴
- [x] 历史会话普通文字不展示，相近修饰键可恢复为快捷键
- [x] 手动按键录入拒绝普通文字并保存到右键时间
- [x] 按键提示显示约 1.5 秒，新提示替换旧提示且淡入淡出自然
- [x] 全局位置可在画布拖动并保持安全区，预览与导出一致

## Timeline Density & Performance
- [x] 空间足够显示事件名称，不足降级为单点或聚合点
- [x] 放大时间轴后圆点可恢复为名称
- [x] 聚合圆点 Hover 列出全部事件名称和时间
- [x] DOM 仅覆盖可视区及左右缓冲，滚回后事件无丢失
- [x] 播放头逐帧推进不触发事件轨 React 重渲染
- [x] 连续缩放每帧最多合并一次更新，密度档位未变化时不重复全量计算

## Persistence
- [x] 运镜、波纹覆盖、键盘提示/位置、裁剪、音频、音量和参数全部进入 edit.json
- [x] 拖动/滑杆在手势结束保存，连续离散操作按约 500ms 防抖
- [x] 保存中又发生修改时，最终落盘必定是最新 revision
- [x] 保存状态正确经历“保存中… → 已保存 → 淡出”
- [ ] 保存失败保持内存数据并显示不淡出的重试入口，不误报已保存
- [ ] edit.json 缺失或损坏不阻断原始会话加载
- [ ] 自定义音频资产重启后可恢复，资产缺失时局部降级
- [x] 最近编辑时间只在成功保存后更新，会话排序正确

## Compatibility & Code Quality
- [x] 原始 events.json 和原始音视频不被编辑操作改写
- [x] 预览与导出对同一源时间产生一致的相机、波纹、按键和音频结果
- [x] 放大期间任意有效鼠标移动都会更新相机目标，无百分比安全区，边缘钳制无黑边
- [x] 跟随仅过滤像素级抖动，并使用快速轻量平滑，预览与导出结果一致
- [x] 编辑纯逻辑不依赖 DOM，Main/Renderer IPC 类型只从 shared 引用
- [x] 所有相关源文件不超过 300 行，无新增无关依赖或调试日志
- [x] `npm run typecheck` 和 `npm run build` 通过
- [x] timeline、cursor-follow、render、export、audio 及新增专项 smoke 全部通过
- [ ] Windows 与 macOS 人工冒烟通过，长会话操作无明显卡顿
