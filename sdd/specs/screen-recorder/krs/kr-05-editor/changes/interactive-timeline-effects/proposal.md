# Proposal: 可编辑运镜、事件与自动保存 (Proposal)

## 1. Context & Problem Statement

- **Current State**: 时间轴运镜块由录制点击即时派生，只能选择后调整倍率，不能改变开始时间、持续时间或手动创建。事件轨在事件总数超过固定阈值后永久退化为圆点；自定义音频从检查器添加；编辑状态仅保存在内存中。
- **Pain Points**:
  - 用户无法让自动运镜晚于真实点击发生，也无法按成片节奏延长、缩短或新增运镜。
  - 右键与左键行为相同，时间轴缺少统一的“在此时间添加内容”入口。
  - 普通文字按键会进入 `events.json`，存在隐私风险，且尚无预览/导出共用的按键提示层。
  - 运镜、事件、裁剪、音量和自定义音频在重新打开会话后丢失，用户无法确认是否保存成功。
  - 长会话事件密集时不可辨认，时间轴缩放后也不能恢复事件名称。

## 2. Value Proposition

- 把自动运镜从“不可修改的算法结果”升级为可拖动、拉伸、增删和调倍率的时间轴素材。
- 用统一右键菜单降低添加运镜、键盘提示和音频的操作成本。
- 仅保留快捷键、功能键和修饰键，避免普通文字输入进入会话数据。
- 通过自动保存状态与最近编辑时间，让编辑结果可恢复、可确认、可继续。
- 通过密度分档、聚合与可视区虚拟化，让长会话在缩放和播放时仍保持流畅。

## 3. Alternatives Considered

- **继续直接修改派生关键帧**：时间戳既是片段身份又是覆盖键，移动后关联容易丢失，无法稳定连接点击波纹和保存数据，因此拒绝。
- **移动运镜但保留原波纹时间**：会产生“先点击、数秒后才放大”的视觉错位，因此自动运镜与波纹改为关联效果组。
- **每次滚轮缩放全量重渲染事件 DOM**：长会话会产生明显主线程压力，因此采用预计算、密度档位和可视区缓冲。
- **只在画面隐藏普通文字但仍落盘**：不能消除隐私风险，因此未来录制在采集层过滤，历史会话在派生层兼容过滤。

## 4. Success Metrics

- [ ] 运镜片段可新增、删除、整体移动和双端拉伸，预览与导出结果一致。
- [ ] 自动运镜移动或删除时关联波纹同步，手动运镜不生成波纹。
- [ ] 时间轴右键可在目标时间添加运镜、键盘提示和音频，左键仍只负责 seek。
- [ ] 普通文字输入不再进入新会话按键事件，历史会话普通文字不被展示。
- [ ] 任意持久化编辑后出现“保存中… → 已保存 → 淡出”，重新打开会话可恢复。
- [ ] 长会话缩放与自动滚动时，事件轨无明显卡顿且密度足够时恢复名称。
