# Verification Checklist: 跨平台专注预览

## Functional Verification

- [ ] 点击入口或按 `F` 可进入专注预览，再按 `F`、`Esc` 或点击退出按钮可返回编辑器。
- [ ] 专注预览占满当前 Lenza 窗口，但不会进入 macOS 原生全屏 Space 或 Windows 系统全屏。
- [ ] 外部选择 `100%` 后进入专注预览仍完整适应且无滚动条，退出后恢复原 `100%` 状态。
- [ ] 专注预览可独立最大化到屏幕工作区并还原到原窗口位置，过程中不退出专注预览、不隐藏任务栏/菜单栏/Dock。
- [ ] 最大化按钮图标和可访问名称随窗口真实最大化状态同步。
- [x] 从普通窗口进入并在专注模式内最大化后，退出会恢复原窗口尺寸；从已最大化窗口进入则退出后仍保持最大化（2026-08-25 Windows 实机确认）。
- [ ] 顶部工具栏、检查器、完整时间轴及所有编辑手柄均隐藏，最终画面按输出宽高比完整居中并尽可能放大。
- [ ] 进入时不跳回开头，播放位置与播放/暂停状态连续；退出后编辑器缩放和检查器布局恢复。
- [ ] `Space` 可播放/暂停，简化进度条可 seek，输入控件获得焦点时不会误触全局快捷键。
- [ ] 播放且鼠标静止 2 秒后控制栏淡出；鼠标移动、暂停或聚焦控制栏时重新显示。
- [ ] 会话关闭、删除或离开预览页时安全退出，专注模式不写入 `edit.json`。

## UI & Accessibility

- [ ] 悬浮控制栏在深浅主题下均具有足够对比度，焦点状态清晰且按钮具有可访问名称。
- [x] 自动淡出只使用 opacity/transform、不造成布局位移；全局 reduced-motion 规则会压缩过渡时长。
- [x] 舞台适配冒烟覆盖窄高、宽矮、同尺寸与未测量状态，无拉伸或非法尺寸。
- [x] backing 冒烟验证普通模式最高 720p、Retina 专注模式使用完整 1080p、4K 输出专注模式最高 2K。

## Code Quality & Testing

- [x] 复用现有 playback 与视频帧驱动，不增加空转的 `requestAnimationFrame` 或第二套播放器。
- [x] 改动文件均不超过 300 行，无调试日志或无关重构。
- [x] `npm run typecheck` 通过。
- [x] `npm run build` 通过。
- [x] 相关 lint 无新增错误，`git diff --check` 通过。
- [ ] macOS 人工冒烟通过。
- [ ] Windows 人工冒烟通过，或在交付说明中明确列为待验证。
