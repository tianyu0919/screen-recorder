# Proposal: 运镜、静音与背景画布控制 (Proposal)

## 1. Context & Problem Statement

- **Current State**: 编辑器右侧始终展示全部运镜参数，倍率最低为 1.2x；音频只能把增益拖到 0；合成器固定输出 1920×1080，并强制蓝色渐变背景、内边距、圆角和阴影。
- **Pain Points**:
  - 用户不能明确关闭运镜，参数在不需要时仍占据检查器空间。
  - 临时静音会破坏原音量，恢复时必须凭记忆重新拖动。
  - 录制内容被强制裁成圆角并叠加背景，预览和导出都不能忠实呈现源画面边缘。
  - 不需要背景时仍固定导出 16:9，非 16:9 录制会出现留白；需要背景时又无法选择颜色。
  - 高分辨率源直接导出时，设备编码器可能不支持，当前没有可见的降级结果。

## 2. Value Proposition

- 通过“启用运镜”开关和渐进披露，让检查器只展示当前有效的参数。
- 为麦克风、系统音频和每条自定义音频提供可恢复原增益的独立静音。
- 取消强制圆角、阴影和蓝色渐变，让画面按真实源边缘渲染。
- 将背景作为明确的可选图层：关闭时忠实输出源尺寸，开启时使用可配置纯色 16:9 画布。
- 在编码能力不足时按比例降档，并在界面中明确显示实际输出尺寸。

## 3. Alternatives Considered

- **关闭运镜时删除片段**：会造成不可逆编辑丢失，因此保留片段与参数，只暂停派生和编辑。
- **用音量 0 表示静音**：无法可靠恢复用户原增益，因此静音状态与 gain 分离持久化。
- **继续固定 1920×1080，仅将背景设透明**：仍改变源宽高比与导出尺寸，因此关闭背景时改用源尺寸。
- **保留小圆角以统一风格**：会改变实际录制内容，且不同来源边缘不一致，因此合成输出完全移除强制圆角和阴影。
- **任意自定义导出尺寸**：增加编码与布局复杂度，本期仅提供源尺寸模式和固定 1920×1080 背景模式。

## 4. Success Metrics

- [ ] 关闭运镜后预览/导出固定 1.0x，点击波纹和键盘提示仍显示，重新启用后原片段与参数恢复。
- [ ] 运镜启用时全局与单段目标倍率均可选择 1.0x。
- [ ] 三类音频可独立静音/恢复，滑杆位置不变，重开会话与导出结果一致。
- [ ] 合成画面不再强制圆角、阴影或蓝色背景。
- [ ] 背景关闭时按源比例和尺寸输出；背景开启时以纯色 1920×1080 画布居中承载源画面。
- [ ] 超出编码能力时自动等比降档，并在导出前后显示实际输出尺寸。
