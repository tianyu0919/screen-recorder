# Verification Checklist: 运镜、静音与背景画布控制

## Functional Verification
- [ ] 运镜默认开启，关闭后参数收起、画面固定 1.0x，点击波纹与键盘提示仍正常
- [ ] 关闭运镜不删除片段或参数；重新开启后预览与导出恢复原效果
- [ ] 禁用时运镜块弱化可见，新增、拖动、拉伸、删除和倍率修改均不生效
- [ ] 全局目标倍率和选中片段倍率最低均可设为 1.0x
- [ ] mic/system/custom 各轨静音不移动音量滑杆，取消静音恢复原增益
- [ ] 静音与增益写入 edit.json，重开会话和导出结果一致
- [ ] 背景默认关闭，旧会话首次打开无蓝色背景、padding、圆角或阴影
- [ ] 背景关闭时预览与导出采用源比例和源尺寸，内容完整填满画布
- [x] 开启背景并切换颜色后关闭，预览立即停止使用该颜色；重新开启时仍恢复上次选色（macOS，2026-08-25）。
- [ ] 开启背景并切换颜色后关闭，MP4 导出不使用已关闭的背景色。
- [ ] 背景开启时输出 1920×1080，源内容等比居中，留白使用所选纯色
- [ ] 预设色、系统颜色输入和 HEX 输入同步；非法 HEX 不覆盖有效值
- [ ] 超出编码能力时自动输出最大可用等比偶数尺寸，并清楚显示实际尺寸
