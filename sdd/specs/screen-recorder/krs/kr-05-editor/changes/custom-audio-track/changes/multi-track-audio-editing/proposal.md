# Proposal: 多轨音频时间线与片段裁剪

## 1. Context & Problem Statement

- **Current State**: 外部音频都挤在同一条“音频”行和同一个控制列表中，虽然已有拖动、双端裁剪、音量、预览和导出能力，但多个素材难以区分和精确编辑。
- **Pain Points**: 连续添加多个音频后缺少清晰的上下轨层级；用户无法按音轨组织多个片段，也难以判断当前裁剪、移动或音量操作作用于哪段素材。

## 2. Value Proposition

- 在原始录音波形下提供接近常见视频编辑器心智的多轨布局。
- 一条音轨可容纳多个片段，用户能直观看见素材位置、波形和裁剪范围。
- 保留现有预览、导出和自动保存一致性，不要求用户重新导入旧工程素材。

## 3. Alternatives Considered

- **继续使用单行并叠放所有片段**：改动小，但无法解决多素材遮挡和操作归属不清。
- **每个文件固定生成一条轨道**：界面清晰，但无法把多段旁白或同类 BGM 组织到同一轨道。
- **轨道与片段分离（选定）**：用户可创建多条轨道，每条轨道可放置多个片段；支持跨轨移动，结构清晰且便于后续扩展静音、锁定和淡入淡出。

## 4. Success Metrics

- [ ] 原始录音波形下可创建至少 5 条自定义音轨，滚动和播放无明显卡顿。
- [ ] 每条轨道可放置多个片段，片段可定位、跨轨移动和双端非破坏裁剪。
- [ ] 保存重开、预览和导出对轨道、片段、裁剪、增益与静音结果保持一致。
