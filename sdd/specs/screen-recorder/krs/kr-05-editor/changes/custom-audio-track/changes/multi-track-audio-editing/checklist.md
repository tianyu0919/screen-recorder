# Verification Checklist: 多轨音频时间线与片段裁剪

## Functional Verification

- [ ] 原始 mic/system 波形与自定义音轨分层展示，不再把所有外部音频挤在同一行。
- [ ] 可创建、重命名和删除多条自定义音轨，非空轨删除具有二次确认。
- [ ] 同一轨道可放置多个独立片段，并正确阻止同轨重叠。
- [ ] 片段可水平定位、跨轨移动、删除和双端裁剪，最短长度为 100ms。
- [ ] 拖动冲突有明确反馈并回到最近合法位置，不覆盖或静默截断其他片段。
- [ ] 轨道音量、静音和片段增益在预览中实时生效且互不串轨。
- [ ] 多轨导出的位置、裁剪、增益和静音与预览一致。
- [ ] V1 扁平自定义音频可无损迁移，原片段位置、裁剪、增益和资产引用不变。
- [ ] 保存并重开后，轨道顺序、名称、控制状态和全部片段完整恢复。
- [ ] 单个资产缺失只禁用对应片段，不阻断其他轨道预览或导出。

## Code Quality

- [ ] 跨进程契约仅从 `shared/` 引用，编辑文档迁移为纯函数。
- [ ] PCM/AudioBuffer 不进入 zustand 或 edit.json，不复制大对象到逐帧路径。
- [ ] 相关组件与模块均不超过 300 行，无调试日志和无关依赖。
- [ ] `npm run lint`、`npm run typecheck` 和 `npm run build` 通过。
- [ ] timeline、audio、edit-document 与 export smoke 全部通过。

## Performance & Manual Testing

- [ ] 5 条轨道、20 个片段连续播放时，波形和事件轨不随播放头逐帧重渲染。
- [ ] 长时间线滚动只绘制可视区需要的波形细节，无明显输入延迟。
- [ ] macOS 与 Windows 完成添加、跨轨移动、裁剪、自动保存、重开和导出冒烟。
- [ ] 原有录制音频增益、自定义音频基础编辑和 MP4 导出无回归。
