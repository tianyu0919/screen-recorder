# Proposal: 后台导出队列与默认导出目录

## Context

当前导出 Worker 绑定详情页导出 Store；返回列表会调用 reset 并终止任务，完成后还必须等待“另存为”对话框，无法可靠后台完成。

## Proposed Change

- 将导出生命周期提升为应用级单执行队列，任务在点击时冻结编辑快照。
- 返回列表、切换录像或隐藏窗口不取消；真正退出时确认取消。
- 默认直接保存到应用设置的导出目录，保留“导出到…”单次选择。
- 所有保存不覆盖同名文件，自动追加序号。
- 在应用右上角提供可折叠的全局进度、队列、成功和失败提示。

## Success Criteria

- [ ] 页面切换后当前导出继续且进度可观察。
- [ ] 多个请求串行执行，不并行争抢编码资源。
- [ ] 自动与手动导出均不覆盖已有文件。
- [ ] 应用重启后恢复默认导出目录设置；不恢复已中断的内存队列。
