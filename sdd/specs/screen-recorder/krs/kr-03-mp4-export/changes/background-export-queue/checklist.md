# Checklist: 后台导出队列与默认导出目录

- [x] 返回列表、切换录像和隐藏窗口不会终止活跃导出
- [x] 点击导出时详情页不出现全局提示；返回列表后才展开提示并在约 2 秒后收缩
- [x] 多个录像导出按点击顺序串行，内容使用各自点击时快照
- [x] 可取消当前或等待任务，取消当前后下一任务自动开始
- [x] 右上角提示按 2 秒展开、胶囊、结束展开规则工作
- [x] 展开态标题和正在导出的任务行同时显示百分比与长条进度，进度变化平滑且可访问
- [x] 工具栏仅“导出 MP4”为主 CTA，“另存为”保持次级层级；两者在窄窗口不截断并具备可访问名称
- [x] 后台导出收起胶囊保持紧凑尺寸，完整可见区域可点击，并支持 hover、按压与键盘焦点反馈
- [x] 任务行 × 按钮 hover/focus 时显示状态化提示：进行中/排队为“取消导出”，完成/失败为“关闭提示”
- [x] 多任务导出按队列推进显示 `1/N` 至 `N/N`；成功和失败任务均保留在展开框，只有用户逐项关闭后才移除
- [x] 后台胶囊首次出现时展开约 2 秒；已收起后再次从录像详情返回列表不会重复展开
- [x] 全队列成功后显示成功图标与轻量庆祝效果，约 2.4 秒后平滑关闭；存在失败时保持展开，减少动态效果模式不播放粒子
- [x] 全部成功时保持完成前展开状态：收起胶囊原位显示成功与粒子且不自动展开，展开框原位反馈；两者自动隐藏时长一致
- [x] 默认导出目录可修改、打开并在重启后恢复
- [x] “导出到…”只影响当前任务
- [x] MP4 与 WebM 均自动追加 `(n)` 且不覆盖已有文件
- [ ] 有任务时退出显示确认，确认退出后无半成品
- [x] typecheck、build 与导出 smoke 通过
- [ ] macOS/Windows 人工冒烟通过
