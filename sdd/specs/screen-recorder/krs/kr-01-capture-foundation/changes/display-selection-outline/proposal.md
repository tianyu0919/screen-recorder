# Proposal: 物理显示器选中边框

## 1. Context & Problem Statement

- **Current State**: 录制页只在来源卡片内部展示“已选择”状态。多显示器环境中，用户需要依靠缩略图和“屏幕 N”名称判断实际将被录制的物理显示器。
- **Pain Points**: 显示器名称与排列不一定符合用户直觉，缩略图相似时容易选错；开始录制前缺少跨越应用窗口的直接空间反馈。

## 2. Value Proposition

- 在用户选择整块屏幕时直接标记对应物理显示器，降低误录概率。
- 让 macOS 与 Windows 使用一致、即时且不干扰操作的选择反馈。
- 在采集真正开始前移除提示，避免产品 UI 被写入录制结果。

## 3. Alternatives Considered

- **只强化来源卡片**：实现简单，但仍要求用户把卡片名称映射到物理显示器，无法解决多屏辨识问题。
- **增加“已选择：屏幕 N”浮动标签**：信息更明确，但会遮挡屏幕内容，且用户已要求只显示明显边框。
- **使用呼吸/闪烁动效**：更醒目，但会持续分散注意力并增加视觉噪音，因此采用稳定常亮边框。
- **录制开始后延迟隐藏**：可以保留确认感，但存在被首帧录入的风险，因此必须在启动采集写入前完成隐藏。

## 4. Success Metrics

- [ ] macOS 与 Windows 均能将选中的屏幕来源精确映射到对应物理显示器。
- [ ] 选择、改选和清除来源时，边框状态在一次交互内正确同步。
- [ ] 边框不抢焦点、不拦截鼠标，不影响系统及应用操作。
- [ ] 至少完成一次双显示器录制验证，输出首帧与完整视频均不包含选中边框。
